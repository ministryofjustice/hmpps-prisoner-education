Create a work readiness profile for a prisoner

Use this service to record:

  • whether a prisoner wants support to get work on release
  • what support a prisoner needs to get ready for work
  • what they have set up already

The Prison Employment Lead will use this information to help the prisoner get ready for work.

Start

Before you start, you'll need to know if the prisoner has the right to work in the UK.

If the prisoner wants support you will also need to know if they have:

  • ID - for example, a passport
  • a bank account
  • housing for their release
  • a recent CV
  • a disclosure letter
  • any other work related qualifications or certificates - for example, a heavy goods vehicle (HGV) licence

You'll also need to know what job sectors they are interested in.
